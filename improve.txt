CCNA Master / Claude Code 送信用スクリプト集 v2（81回版対応）
================================================================

これは旧版（50回構成前提・全14ファイル）の作り直しです。
旧版は今のサイト構成に合わないので、使わないでください。

前提の確認（2026-11-27 時点のリポジトリで確認済み）
----------------------------------------------------------------
- 編集先は src/lessons/lNN.json と src/questions/lNN.json（81回の番号）。
- 新規問題の ID は「N{回}-{連番}」。旧ID「P…」は変更禁止（進捗がIDで保存されている）。
- 教科書・授業の設計は src/lessons/DESIGN.md、問題のルールは src/questions/INSTRUCTIONS.md。
- 各スクリプトに共通ルールが全部入っているので、1ファイル単体で送って完結します。

使い方
------
1. ccna-master リポジトリを開いた Claude Code のセッションで使う。
2. 送るのは1回に1ファイルだけ。中身をそのままコピーして貼る。
3. 差分と報告を確認してOKを出してから、commit / push してもらう
   （各スクリプトに「OKまで commit / push しない」と書いてあります）。

送る順番
--------
01_fix-lesson1-undefined.txt          第1課 undefined の修正＋再発検出
02_fix-figure-overflow.txt            第53課の図の見切れ修正＋幅チェック
03_fix-lesson78-structure.txt         第78課のまとめ追加とコードのテキスト化
04_fix-quiz-choice-order.txt          ミニクイズの選択肢ラベルの並び修正
05_strengthen-checks.txt              check.py の強化（検出の追加のみ）
06a_add-questions-lesson19.txt        第19課に問題3問追加（5→8問）
06b_add-questions-lesson37.txt        第37課に問題3問追加（5→8問）
06c_add-questions-lesson53.txt        第53課に問題3問追加（6→9問）
07_explanations-cover-distractors.txt 解説に誤答の理由を追加（第19・37課）
08_show-level-and-lesson.txt          難易度と課の表示＋lv絞り込み
09_review-map-labels.txt              復習マップに中身を表示
10_add-global-search.txt              横断検索
11_show-prerequisites.txt             前提と関連課リンクの表示（前半は確認のみ）
12_lesson-progress-percent.txt        進捗の％表示
13_tighten-lv2-rule.txt               lv2の基準厳格化（原案と棚卸しのみ・実装しない）

注意
----
- 05 は「検出を追加するだけ」で、警告の中身の修正は含みません。
- 07 は 06a・06b の後で送ると、追加した問題にも同じ型が適用できます。
- 11 は前半が「need の有無の確認と提示」まで。データ追加はOKを出してから。
- 13 は原案提示のみ。Claude Code が勝手に問題を書き換え始めたら止めてください。

タスク1（v2）：第1課の「undefined」表示を直し、再発を check で検出する

【共通ルール：必ず守ること】
- 最初に CLAUDE.md を読むこと。教科書・授業を直す場合は src/lessons/DESIGN.md も、問題を作る/直す場合は src/questions/INSTRUCTIONS.md も読むこと。
- 編集先は CLAUDE.md の記載どおり src/lessons/lNN.json と src/questions/lNN.json（今の81回の番号）。src/lessons_v2・src/questions_v2 は切り替え済みか生成元か分からない場合は tools/build.py が読む対象を確認し、build が読む方だけを編集すること。両方を二重に直さない。
- data.json は直接編集しない。src/ を編集し、最後に `python tools/build.py` を実行する（check が「問題なし」になるまで直す）。
- src の JSON を Python で書き換える場合は tools/srcio.py の srcio.save() を使うこと。
- 既存の問題IDは絶対に変えない（進捗がIDで保存されている）。旧ID「P…」は旧50回時代の番号で今の回と一致しないのが正常。新しく作る問題のIDは「N{回の2桁}-{連番2桁}」。
- 問題・教科書はすべてオリジナル。本物の試験問題・市販問題集の文面・図・数値の模倣は禁止。
- 授業セリフ cls / cls.lines には触らない（音声の再生成が必要になるため）。このタスク集のタスクはすべて cls 変更なしで完結させる。
- 教科書 pages のページ数を変える場合は、その回の全問題の page 参照（0始まり）がずれないか必ず確認する。授業で扱っていない内容を足す場合は、pages を直接増やさず tools/extra_pages.py の EXTRA / QPAGE の仕組みを使うこと（CLAUDE.md 参照）。
- 進捗は localStorage キー ccna_master_pub1。既存ユーザーの進捗を壊す変更は禁止。
- このタスクの範囲外は変更しない。範囲外の問題に気づいたら報告に書くだけで直さない。
- 完了したら commit / push はまだせず、「変更ファイル一覧・変更内容の要約・確認結果」を報告して私のOKを待つこと。

【症状：2026-11-27 に実サイトで確認】
- 第1課「ネットワークって何？」の教科書2ページ目、「今日のゴール」の右側に、図が出るはずの場所に「undefined」という文字だけが表示されている。

【作業】
1. 原因を特定する。src/lessons/l01.json の該当ページ（pages の当該要素）の図（svg 等）が欠けているのか、index.html の描画側が無い値をそのまま出しているのかを切り分ける。
2. データ欠落なら、そのページにふさわしい図を既存の図部品（tools/figs.py 等、このリポジトリの既存の作り方）で補う。描画側の問題なら、値が無い場合は図の領域自体を出さないようにする。どちらか一方で済む場合でも、両方の観点で直すかどうか判断し、理由を報告する。
3. 再発防止として tools/check.py に「ページの図・本文などの必須項目が欠けている（undefined になりうる）レッスンを検出する」チェックを追加し、全81回に同種の欠落が無いか走らせる。他の課で欠落が見つかったら、直さずに一覧で報告する（このタスクで直すのは第1課だけ）。

【完了条件】
- 第1課2ページ目に「undefined」が出ない。
- check が追加され、全回分の検出結果が報告されている。

【動作確認】
- `python tools/build.py` が「問題なし」で終わること。
- `python -m http.server` で起動し、http://localhost:8000/ で対象画面を実際に開いて確認すること（デスクトップ幅と375px幅の両方）。

【報告形式】原因、変更ファイル、check の検出結果（全回）を報告すること。
